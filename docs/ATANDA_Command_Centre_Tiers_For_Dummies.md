# ATANDA Command Centre — Tiers, Ingestion & Cartridge for Dummies

*A plain-English, scenario-first guide to what you get, what it costs, and which lane is right for you.*

---

## Before we start: what is the Command Centre, really?

Think of the Command Centre as a **prompt-engineering studio with a built-in inspector**. You bring a rough idea. The HARNESS — a pipeline of seven engines called **F1 → F7** — interrogates it, sharpens it, and produces a certified design document at the end. A bonus engine, **F8 Code DJ**, can take that document and scaffold a starter codebase for you.

There are two ways to pay:

1. **A monthly or yearly subscription** — best if you'll run more than a couple of projects.
2. **Per-project credits** (Ingestion or Cartridge) — best if you only need to ship *one* thing and want a one-time fee.

You can mix and match. A free Explorer account can still buy a single Ingestion or Cartridge credit and use it.

## Part 2 — The Two Per-Project Credits

Subscriptions are great if you'll run lots of projects. But sometimes you only need **one** very specific thing done very well, and a year of unlimited engine use is overkill. That's what the two per-project credits are for.

> **The credits are not subscriptions.** You pay once, you get one project's worth of work, and that's it. You can buy them at any tier — even Explorer.

| | **Ingestion Credit** | **Advanced Cartridge** |
|---|---|---|
| **Price** | $199.99 per project | $499.99 per project |
| **You bring** | 1 existing document (PDF, Word, or pasted text) | Up to 5 documents, prior SPCs, plus optional links to your Git repo / database |
| **System produces** | A full HARNESS session seeded by your doc, ending in a **PWDD** (PromptWare Design Document) | A full HARNESS session pre-loaded with all your context, also ending in a **PWDD / MVP PDD** |
| **Engines unlocked for this project** | F1 → F7 | F1 → F7 |
| **F8 included?** | No (needs Architect tier) | No (needs Architect tier) |
| **Best for** | "I already wrote a brief — turn it into something certified" | "I have a real project with lots of context — pull it all together properly" |

A few important rules in plain English:

- **You don't need a subscription to buy a credit.** A free Explorer account can buy an Ingestion or Cartridge credit and immediately run a full F1–F7 session with it.
- **Credits don't expire.** Buy now, use whenever.
- **If something fails, you don't lose the credit.** If the system can't finish your session for any reason, the credit automatically goes back to "available" and you can try again.
- **You don't get F8 for free.** Both credits stop at F7 (the certified MVP PDD). If you also want code scaffolded, either upgrade to Architect for one month, or pass the certified document to a developer (which is exactly what it's designed for).

## Part 4 — Things people get wrong (the FAQ)

**"If I buy an Ingestion Credit on a free account, do I get F8 too?"**
No. F8 Code DJ is gated by the Architect subscription — credits don't unlock it. The credit unlocks F1 → F7 *for that one project*.

**"What happens if a session crashes halfway? Do I lose my credit?"**
No. Credits are refunded automatically. The system marks the credit as "available" again and you can re-run.

**"Can I use one Cartridge credit to start two projects?"**
No. One credit = one project = one session. If you want a second one, buy another credit (or move to a subscription if you'll do this regularly).

**"Do daily limits reset at my local midnight?"**
No, they reset at midnight UTC. The session-detail page shows your current count for the day.

**"What's the difference between IPDD and PWDD again?"**
- **IPDD = INPUT.** *Ingestion Product Design Document.* The thing **you** wrote and feed into the system (your brief, your existing spec).
- **PWDD = OUTPUT.** *PromptWare Design Document.* The thing **the HARNESS** gives you back at the end of an ingested or cartridge session — certified, with a public verification URL.

You feed it an **IPDD**; you receive a **PWDD**.

**"If I cancel my subscription, do I lose access immediately?"**
No. You keep paid access until the end of the period you've already paid for.

**"Can I escalate a single session past my tier's caps?"**
Yes — when an engine refuses to run because of tier or daily-limit caps, you can request an **escalation** for that specific session. If granted, the gate is bypassed just for that one session, so a stuck Practitioner project doesn't force a tier upgrade.
