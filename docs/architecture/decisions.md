# Architecture decisions

Standing decisions that govern how new code is written here. Defer to these unless you have a deliberate reason to change them — and if you change one, update this file.

- **Contract-first.** Every endpoint is declared in `openapi.yaml` first; the server uses generated Zod for request bodies, the client uses generated React Query hooks. Response shapes are returned as plain objects typed by the generated TS interfaces (response Zod schemas are not generated by Orval).
- **App-layer authorization, no RLS.** Every Drizzle query that touches user-owned data must filter on `req.localUser.id`. There is no Postgres RLS net.
- **Stripe webhook receives raw body and is mounted before JSON parsers.** `/api/webhooks/stripe` is a dedicated mini-router in `app.ts` with `express.raw({type:"application/json"})` so signature verification works.
- **Tier gating + escalation bypass.** `requireTier("PRACTITIONER")` on F5/F6/F7; if the request body has a `sessionId` with an existing `harness_escalations` row, the gate is bypassed for that session.
- **Daily rate-limit counters live on the subscriber row** (`f{1..8}_today`). A guarded `/api/cron/reset-harness-limits` (header `x-cron-secret`) resets them.
- **Admin role** = Clerk `publicMetadata.role === "admin"` OR the user's email is in the `ADMIN_EMAILS` env allowlist. Stored on the local `users.role` column at JIT-sync time.

## Drift from contract-first

- **Orgs + Activity endpoints are NOT in `openapi.yaml`** (same precedent as `/api/cartridge`). Routes live in `routes/orgs.ts` + `routes/activity.ts` with inline Zod validation, and the command-centre frontend talks to them via the hand-rolled `src/lib/api.ts` wrapper (not generated React Query hooks). If you later move these into the spec, make sure the org-visibility PATCH stays on the dedicated path `PATCH /api/sessions/:id/org-visibility` rather than being folded into `UpdateSessionBody` — the latter would re-generate Zod across the whole codegen and risk subtle breakage.
- **Cartridge multipart upload** (`POST /api/cartridge`) is also out-of-spec because Orval emits `Blob` refs for multipart bodies that break the api-zod tsconfig.
