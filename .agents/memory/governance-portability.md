name: Governance portability
description: Target customization must preserve mandatory ethical safeguards; criteria installation is not evaluation or release.
---

Full target integration must cover GRO, ZPOS+5 and the Honesty Gate. Fragmented
exports are partial preparation, not approval to omit safeguards in production.
Distributed placement can be valid only when all mandatory controls have real
bindings and verified coverage. Target formatting may change; the Ethical
Engine's requirements may not.

**Why:** The user explicitly required Azure F10/F11 integration to fit Azure
without compromising the Ethical Engine.

**How to apply:** Keep preparation, delivery, installation, independent
evaluation and promotion separate. Neither a full policy package nor hashes
prove target enforcement. Do not call deterministic SAVANT module selection a
SAVANT FIT verdict or activate an unwired target adapter.

Governance criteria versions require explicit new governed revisions rather
than silently changing historical artifacts. Legacy/unassessed content must
not gain a positive safety or certification claim merely because criteria
were added.

**Why:** Mandatory installation and honest assessment are different
requirements; historical review provenance must remain trustworthy.

**How to apply:** Version substantive criteria changes, retain the previous
source, and keep model-reported assessments distinct from independently
verified results.
