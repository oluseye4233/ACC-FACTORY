# Onboarding books vs platform

Two manuscripts have been supplied as candidate onboarding material for ATANDA Command Centre.

- **The Atomic Prompt: Book One (Of Gods and Monsters)** — the *parent doctrine*. Uses the platform's exact framework set: JST index (Jobs/Skills/Talent), the Atomic Prompt 7-tuple `(I,O,C,T,M,V,Δ)` = F2, the FORGE 7-phase pipeline = F1–F8, BONSAI cultivation = exemplar library + DE-SPC evolution, HIVE intelligence = HIVE 14-D, JCSE 0–50 (3 dimensions) = the platform's cert scoring, ZPOS = ZPOS+5, quality gates, semantic-preservation = PFP drift, evolution decision framework = DE-SPC. Healthcare/regulated framing (ACME). Author: Oluseye Shay Amusa / "Dr. Amusa" (Junglenomics).
- **Context Craft: The Last Human Skill** — covers ONLY the seven context pillars (SYSTEM/ROLE/INSTRUCTION/DATA/CONSTRAINT/FORMAT/EXAMPLE) = F1's diagnostic = JCSE Dimension 2 only. In the Atomic Prompt manuscript, Context Craft is explicitly **Chapter Four**.

**Verdict (durable):** Atomic Prompt is the onboarding *spine* (covers ~12/16 platform features as core; carries the JST displacement motivation arc that drives subscription). Context Craft is the *Chapter-4 deep-dive companion* (best hands-on per-chapter scaffold, but single-engine coverage). Sequence them as a set: Atomic Prompt → Context Craft, mirroring JST → F1 → F2 → FORGE.

**Why:** the platform is literally named/architected after Atomic Prompt's doctrine (FORGE.BONSAI HARNESS, JCSE, JST, HIVE). A book teaching one dimension of one engine can't be the spine of an 8-engine pipeline.

**How applied:** the Ascension Protocol (`/ascension`) makes this spine concrete — a 13-rung ladder anchored to Atomic Prompt chapters (Context Craft pillars are rung 5 / Ch.4), seeded by the JST self-assessment and proven by real engine/artifact/badge/org signals.
