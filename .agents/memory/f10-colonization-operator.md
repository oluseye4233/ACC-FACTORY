SAVANT CONNECTOR is a distinct F10 protocol surface, not a reinterpretation of export, provider delivery, or signed release acknowledgements. It sequences C0–C8 but owns no verdict, certificate, credential, consent, or promotion authority.

**Why:** The governing SPC explicitly says a fully built operator with unwired SAVANT, connector/analyzer, Vault/Consent, and UCG-COL dependencies must refuse. Treating existing delivery receipts as colonization would falsely claim capabilities and certification.

**How to apply:** Keep SAFE_LIFE as the only write-path mode. Fail closed with a cited phase, constraint/invariant, cause, and required action. Physical targets require a fully validated F9 attestation; agent gateways can never advance beyond C4. UCG-COL uses a 0.9 threshold and deployment-subject certificate contract; stage and promotion consents are separate, one-time, and exact-write-bound. Never trust caller-supplied certificate or Vault readiness: promotion stays unreachable until server-owned UCG-COL authority and Vault adapters validate them.
