The Exemplar Library is the authenticated internal catalog and the source
catalog for future Sphinx supply. The user explicitly replaced the old
separate-upload model with an owner-controlled LIBRARY ARTIFACT / SPHINX
ARTIFACT switch on the same library copy. Eligible commercial kinds are MA,
SPC, MPDD and PDD. F0 reports remain advisory and never qualify.

**Why:** Opening Sphinx should reuse Exemplar's catalog, source records and
presentation rather than require rebuilding a second marketplace. Library
copies must still survive deletion of their original sessions/artifacts.

**How to apply:** Preserve independent library snapshots and authenticated
internal access. Never automatically commercialize uploads, canonical platform
references or artifacts merely because they passed review. Only the owner
opts in, with explicit consent; only active, qualified artifacts can be selected.
Archive, withdrawal, revoked review or content changes must remove public
eligibility. Public launch is explicit and closed by default; selecting before
launch means queued, not for sale. Internal review is evidence recorded by a
reviewer, not independently executed testing.

The Sphinx source doctrine's baseline is JCSE ≥35/50, ≤100,000 tokens,
documentation, basic test evidence and semantic versioning; commercial rights
and safety must also be reviewed. Keep that baseline explicit rather than
inventing certification claims. A public metadata catalog does not activate
checkout, licensing or commercial delivery.
