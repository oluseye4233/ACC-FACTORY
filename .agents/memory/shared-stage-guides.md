Stage explainers and demonstrations are shared ATANDA teaching guides, not videos generated from each subscriber's artifacts or Synthesia account.

**Why:** The user explicitly selected shared stage guides over project-specific videos. Reusing reviewed teaching material avoids exporting private project context and paying for a new render whenever a stage is viewed.
