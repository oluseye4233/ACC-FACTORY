---
name: Project-first artifact titles
description: Owner-required prefix invariant for all newly produced project artifacts.
---

Every artifact title created during the production process must start with the
owning project name. Use `<Project name> — <Artifact description>`, retaining
stage/type and Boomerang `Upgraded N` suffixes without duplicating the prefix.
This is separate from the download filename convention.

**Why:** The user explicitly made project-first artifact titles an invariant
to keep production artifacts clearly attributable to their project.

**How to apply:** Follow ART-TITLE-001 in
`docs/upgrade-program/artifact-title-invariant.md` for new artifacts and derived
versions. Do not rename immutable historical outputs or claim live enforcement
merely because the policy has been recorded.
