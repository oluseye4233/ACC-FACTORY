---
name: Boomerang review boundary
description: Supporting-work acceptance must remain separate from execution and protected workflow authority.
---

Boomerang covers the whole F-process as an origin-bound supporting-work loop, not a route around normal workflow gates. Acceptance means the owner reviewed supporting input; it does not automatically inject it into prompts, run an engine, certify, establish custody or authorize release.

**Why:** The process-wide integration was requested after a review identifying that returning a package alone proves delivery, not adoption or clearance. Automatically adopting arbitrary returned text would also cross a prompt-injection and evidence-trust boundary.

**How to apply:** Keep source-version checks and explicit review decisions. Use stage labels rather than assuming numeric cockpit IDs equal F numbers. F0 belongs to an advisory engagement; F9.5 and F12 support must not imply those protected operations are activated. Never invent departure evidence for historical SPC Player runs that did not retain it.

The source baseline is intentionally conservative: any production artifact change in the originating session requires a fresh request. Support attachments themselves must not cause baseline drift.

**Why:** Downstream support can rely on upstream artifacts; checking only the visibly selected stage could accept advice after its inputs changed.

**How to apply:** Narrow this rule only with explicit dependency evidence, not by simply ignoring unrelated-looking artifact changes.

Score-driven rework is an explicit user-authorized loop: JCSE <45 or MATHMON
<70 recommends the latest exact-stage artifact for SPC Player, then requires
F1 re-ingestion to address the recorded shortcomings.

**Why:** The user requested automatic source selection and recommendations
linked to internal evaluation, not generic supporting work without correction.

**How to apply:** Retain exact artifact scores and feedback, distinguish absent
evidence, reject stale sources/evaluations before rework, and prepare completed
output at F1. Keep normal ingestion confirmation and fresh evaluation; never
silently spend credits, overwrite entered input, alter old scores or promote
the recommendation into certification or Boomerang acceptance.
